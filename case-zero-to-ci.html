Zero to daily CI in one quarter

I joined a product with no automated tests and a regression pass that consumed a week of manual effort before every release. I built the framework, the pipeline and the reporting layer from an empty repository.

Context

Prodly builds deployment and data-management tooling for Salesforce — a domain where the application under test is itself highly configurable, so the same feature behaves differently across org configurations. Coverage was entirely manual, and the regression checklist grew with every release while the time available to run it did not.

The problem

The cost was not just the week of manual effort. It was that regression only ran at the end, so defects were found at the point where fixing them was most expensive, and the checklist quietly shrank under deadline pressure. Nobody could say what coverage actually existed.

What I built

The framework. Playwright and Cypress in TypeScript and JavaScript, structured so that Salesforce org configuration is a parameter rather than a hardcoded assumption. Page objects and fixtures were designed around the product's own vocabulary so that a test reads like the feature it covers, which is what keeps a suite maintainable after the person who wrote it leaves.

The pipeline. Daily CI execution, with the suite structured into fast smoke and full regression tiers so that feedback arrived at a useful speed rather than all at once.

The reporting layer. This is the part that changed the team's relationship with QA. I deployed an Allure reporting pipeline hosted on AWS S3, giving every stakeholder a self-serve HTML dashboard of execution trends, flakiness patterns and coverage gaps. Before it existed, QA status was something people asked me for. After it, it was a link.

Supporting work. API validation of REST endpoints via Postman and Swagger — data correctness, response-time SLAs and error boundary behaviour. Datadog for log monitoring and DBeaver for SQL validation, confirming backend state matched what the UI displayed. I also served as Salesforce System Admin within QA, provisioning test environments and validating data migration accuracy.

Result

  • More than 60% of manual regression effort eliminated, from a zero-automation baseline.
  • Daily CI execution replaced end-of-cycle manual passes, moving defect discovery earlier where it is cheapest to act on.
  • The first self-serve QA dashboard in the company — reports stopped being distributed by hand, and stakeholder trust in QA metrics went up because the numbers were always current.
  • Part of 200+ automated test cases authored across regression, integration and end-to-end suites.
